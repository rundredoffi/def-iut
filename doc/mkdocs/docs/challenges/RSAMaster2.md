# RSA Master 2 <br>

## Introduction <br>

Vous avez intercepté deux messages chiffrés envoyés à deux destinataires différents. Les deux messages ont été chiffrés en utilisant la même valeur de \( e \) et les modules \( n_1 \) et \( n_2 \) ont un facteur commun.<br>

Votre tâche est de déchiffrer ces deux messages pour trouver les flags.<br>

Les paramètres RSA (n1, n2, e, ciphertext1, ciphertext2) sont donnés ci-dessous :<br><br>

- \( n1 = 123457 \)
- \( n2 = 123493 \)
- \( e = 65537 \)
- Message chiffré 1 : 100000
- Message chiffré 2 : 200000<br><br>

Les flags sont les messages déchiffrés.<br><br>

## Objectif

Déchiffrez ces deux messages.<br><br>

## Flag

Le flag se présente doit être présenté sous cette forme : [a,b] => a et b étant respectivement un message déchiffré.<br><br>
