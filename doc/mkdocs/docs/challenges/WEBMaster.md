# WEBMaster<br><br>

## Introduction<br>

Bienvenue dans le défi "WEBMaster" !<br><br>

Vous ne savez pas quoi faire de votre vie ? Nous avons une idée d'activité pour vous ! Que dites-vous de compter le nombre d'occurences d'un mot dans une page Web ? Trouvez les 5 mots les plus présents dans la page web !<br><br>

## Objectif<br>

Trouvez les 5 mots les plus utilisés dans la page Web

## Flag<br>

Le flag est une chaine de caractères à `[('1', a), ('2', b), ('3', c), ('4', d), ('5', e)]`. <br>
Le chiffre dans un couple représente le mot et la lettre représente le nombre d'occurences. <br><br>
