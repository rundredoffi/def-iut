# Hash Master<br><br>

## Introduction

Vous avez intercepté plusieurs mots de passe hachés à l'aide de l'algorithme SHA-256. Votre tâche est de retrouver les mots de passe en utilisant une Rainbow Table pré-générée. Les mots de passe sont composés de lettres minuscules et de chiffres.

Les hachages SHA-256 sont donnés ci-dessous :<br><br>

- Hachage 1 : 5e884898da28047151d0e56f8dc6292773603d0d6aabbddc4b7c231a4cfa89c6
- Hachage 2 : 6cf615d5d5f897f0f5d9d66ad7f9d97c23d6fc627c01a3e9e14414f45761c0ae

Les flags sont les mots de passe retrouvés.<br><br>

## Objectif

Trouvez les deux mots de passes en clair.

## Flag

Le flag doit être présenté de cette manière => [a,b] avec a et b les mots de passes retrouvés.<br><br>
